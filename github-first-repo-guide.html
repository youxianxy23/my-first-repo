GitHub 新手建仓图文指南

零基础也能照做 · 不用写代码 · 不用命令行 · 顺便记英语和日语

开始之前：你需要先有一个 GitHub 账号。打开 github.com → 点右上角 Sign up 用邮箱注册（免费）。注册并登录后，再按下面的步骤操作。

完成度清单（每做一步打勾）

第一部分：在网页上建好第一个仓库

仓库（Repository）可以理解成一个「带历史记录的网盘文件夹」。下面 6 步，全程用网页点鼠标完成。

1

登录后，点右上角的「＋」号 → 选 New repository

登录 github.com 后，页面右上角有一个头像和一个 ＋ 号。点开它，在菜单里选第一项 New repository（新建仓库）。

github.com 登录后的右上角
Notifications ＋ New ▾ 你的头像

点 ＋ → 菜单第一项就是 New repository。
repository（仓库）在日语里叫 リポジトリ。

2

填写仓库名（Repository name）

在 Repository name 输入框里写个名字。建议用英文小写、短一点，比如 my-first-repo 或 japanese-notes（后面用来放日语笔记很合适）。

Create a new repository
Create a new repository
Owner 你的用户名 ▾ /
Repository name 2
Great repository names are short and memorable.
小提示：名字只能含字母、数字、横杠 - 和下划线 _，不能空格。仓库名以后能改，先随便起一个也行。
3

（可选）写一行描述 Description

Description (optional) 是选填的「一句话介绍」。可以留空，也可以写「我的日语学习笔记」之类。

Create a new repository
Description (optional)
4

选择 Public（公开）

下面有 Public 和 Private 两个选项。新手选 Public 即可（所有人可见，但只是你放的文件，不用担心隐私；而且公开仓库免费）。

Create a new repository
Public Anyone on the internet can see this repository. You choose who can commit.
Private You choose who can see and commit to this repository.
5

勾选「Add a README file」

往下翻，勾选 Add a README file。README 就是仓库的「首页说明」，勾上后 GitHub 会自动帮你生成一个，省得你手动建。建议勾上。

Create a new repository · 初始化选项
Add a README file
Initialize this repository with a README.
Add .gitignore   None ▾
Choose a license   None ▾
6

点绿色按钮「Create repository」

页面最下方有一个绿色按钮 Create repository，点它！几秒后你就进入新仓库页面，说明建仓成功。

Create a new repository
成功：看到仓库页面（文件列表里有一个 README.md）→ 恭喜，你的第一个 GitHub 仓库建好了！

第二部分：建好之后怎么操作

仓库建好只是开始。下面是你之后最常用、也必须看懂的 5 个操作。建议照着做一次，印象最深。

A

上传文件（拖拽即可，不用命令行）

在仓库页面点 Add file → Upload files，然后把电脑里的文件直接拖进虚线框（或点 choose your files 选文件）。

你的仓库页面
README.md Add file ▾
把文件拖到这里
或点 choose your files
这就是你「上传之后」最常用的动作：把日语笔记、图片、文档拖进来就行。
B

写提交说明（Commit message）

上传或改动文件后，页面底部会出现 Commit changes 区域。在 Add a commit message 里写一句话说明「这次改了什么」，比如 添加第一天五十音图笔记，然后点绿色 Commit changes。

Commit changes
Add a commit message
Extended description（选填，写更细的说明）
每一次「提交（commit）」都会留下记录，你可以随时回看改了什么——这就是 GitHub 最厉害的「历史版本」功能。commit 在日语里叫 コミット。
C

编辑 / 删除已有文件

点开任意文件（如 README.md），右上角有 Edit 按钮可以改内容；改完同样写 commit message 提交。想删文件，进文件后点右上角「···」菜单 → Delete file。

README.md 文件页面
Edit ···
Edit = 改内容；··· → Delete file = 删除
D

填仓库简介（About）

仓库页面右侧有 About 栏，点右边的设置（齿轮）图标可以写一句话简介、加网址链接、选一个「话题标签（Topics）」。这是别人（和未来的你）快速了解这个仓库的入口。

仓库右侧栏
About   (设置)
在这里写简介 / 加链接 / 加 Topics 标签
E

（进阶）用 GitHub Pages 做个人网页练日语

等你放了一些日语笔记，可以把仓库变成一个网页：进仓库 Settings → 左侧 Pages → Source 选 main 分支 → Save。之后会得到一个网址，谁都能打开看你的日语笔记。这是练写作的好舞台。

Settings → Pages
Branch（分支）
main ▾/ root ▾
保存后稍等一两分钟，就能用网址访问你的网页。

附：界面英文 → 中文 → 日语 小抄

GitHub 界面几乎全是英语，但很多词在日语里是直接音译的「片假名」。记一个英语词，日语那栏基本自动会读——这就是你两个一起学的最大红利。

英语（界面上看到的）中文日本語（读音）
Repository仓库リポジトリ (ripojitari)
New repository新建仓库新しいリポジトリ
Commit提交 / 改动记录コミット (komitto)
Public / Private公开 / 私有公開 / 非公開
README说明文档（首页）リードミー
Add file添加文件ファイルを追加
Upload files上传文件ファイルをアップロード
Edit编辑編集 (へんしゅう)
Settings设置設定 (せってい)
Branch分支ブランチ (buranchi)
Star收藏スター (sutā)

把这份指南上传到你的仓库（闭环练习）

这份 HTML 文件本身，就是你第一个要上传的「练习文件」。照下面做，等于把今天学的全用了一遍：

①

进入你刚建好的仓库

登录 github.com，点左上角你的头像 → Your repositories → 点开 japanese-notes（或你起的名字）。

②

上传这份文件

点 Add file → Upload files，把本地的 github-first-repo-guide.html 拖进去。Commit message 写 上传GitHub建仓指南，点 Commit changes。

③

以后随时回看

文件就在仓库里了。任何时候登录 github.com 打开这个仓库，就能重新看这份指南——不用再问，你自己就「看得懂、做得来」。

本指南为离线 HTML，可双击用浏览器打开，也可上传到 GitHub 长期保存。
