# GitHub 新手建仓图文指南（零基础 · 含日语）

> 适用：没写过代码、没用过 GitHub，同时想学日语/英语的人。
> 全程用网页点鼠标完成，不需要写命令行。

---

## 开始之前

先有一个 GitHub 账号：打开 github.com → 点右上角 **Sign up** 用邮箱注册（免费）。
注册并登录后，再按下面步骤操作。

### 完成度清单（每做一步打勾）

- [ ] 已注册并登录 github.com
- [ ] 建好了第一个仓库（Repository）
- [ ] 成功上传了一个文件
- [ ] 写了一条提交说明（commit message）
- [ ] 看懂了界面上的英文单词

## 第一部分：在网页上建好第一个仓库

仓库（Repository）可以理解成一个「带历史记录的网盘文件夹」。
下面 6 步，全程用网页点鼠标完成。

### 第 1 步：点右上角「＋」→ 选 New repository
登录 github.com 后，页面右上角有一个头像和一个 **＋** 号。
点开它，在菜单里选第一项 **New repository**（新建仓库）。
> 注：repository（仓库）在日语里叫 リポジトリ。

### 第 2 步：填写仓库名（Repository name）
在 **Repository name** 输入框里写个名字。建议英文小写、短一点，
比如 `my-first-repo` 或 `japanese-notes`（放日语笔记很合适）。
> 名字只能含字母、数字、横杠 `-` 和下划线 `_`，不能空格。以后能改。

### 第 3 步：（可选）写一行描述 Description
**Description (optional)** 选填，可留空，也可写「我的日语学习笔记」。

### 第 4 步：选择 Public（公开）
下面有 **Public** 和 **Private** 两个选项。新手选 **Public** 即可
（公开仓库免费，只是你放的文件，不涉及隐私）。

### 第 5 步：勾选「Add a README file」
往下翻，勾选 **Add a README file**。README 是仓库的「首页说明」，
勾上后 GitHub 会自动生成，省得手动建。建议勾上。

### 第 6 步：点绿色按钮「Create repository」
页面最下方绿色按钮 **Create repository**，点它！
几秒后进入新仓库页面（文件列表里有一个 README.md）→ 建仓成功。

---

## 第二部分：建好之后怎么操作

### A. 上传文件（拖拽即可，不用命令行）
仓库页面点 **Add file** → **Upload files**，
把电脑里的文件直接拖进虚线框（或点 choose your files 选文件）。

### B. 写提交说明（Commit message）
上传或改动文件后，页面底部出现 **Commit changes** 区域。
在 **Add a commit message** 写一句话说明「这次改了什么」，
比如「添加第一天五十音图笔记」，再点绿色 **Commit changes**。
> 每一次 commit 都会留记录，可随时回看改了什么——这就是 GitHub 的「历史版本」。
> commit 在日语里叫 コミット。

### C. 编辑 / 删除已有文件
点开任意文件（如 README.md），右上角 **Edit** 按钮改内容，
改完写 commit message 提交。想删文件：进文件后点「···」菜单 → **Delete file**。

### D. 填仓库简介（About）
仓库页面右侧 **About** 栏，点右边设置（齿轮）图标可写一句话简介、
加网址链接、选「话题标签（Topics）」。

### E. （进阶）用 GitHub Pages 做网页练日语
进仓库 **Settings** → 左侧 **Pages** → Source 选 **main** 分支 → Save。
保存后稍等一两分钟，会得到一个网址，谁都能打开看你的日语笔记。

## 附：界面英文 → 中文 → 日语 小抄

GitHub 界面几乎全是英语，但很多词在日语里是直接音译的「片假名」。
记一个英语词，日语那栏基本自动会读——这是你两个一起学的最大红利。

| 英语（界面上看到的） | 中文 | 日本語（读音） |
|---|---|---|
| Repository | 仓库 | リポジトリ (ripojitari) |
| New repository | 新建仓库 | 新しいリポジトリ |
| Commit | 提交 / 改动记录 | コミット (komitto) |
| Public / Private | 公开 / 私有 | 公開 / 非公開 |
| README | 说明文档（首页） | リードミー |
| Add file | 添加文件 | ファイルを追加 |
| Upload files | 上传文件 | ファイルをアップロード |
| Edit | 编辑 | 編集 (へんしゅう) |
| Settings | 设置 | 設定 (せってい) |
| Branch | 分支 | ブランチ (buranchi) |
| Star | 收藏 | スター (sutā) |

## 把这份指南上传到你的仓库（闭环练习）

这份文件本身，就是你第一个要上传的「练习文件」。

1. 进入你刚建好的仓库：登录 github.com → 点头像 → **Your repositories** → 打开你的仓库。
2. 点 **Add file** → **Upload files**，把本文件拖进去。Commit message 写「上传GitHub建仓指南」，点 **Commit changes**。
3. 以后随时回看：文件就在仓库里了，任何时候登录都能重新看——不用再问，自己就看得懂、做得来。
